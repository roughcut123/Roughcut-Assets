# THE COURIER BAG — CHAPTER CARDS

Nine alpha overlays for the Courier Bag tutorial: a contents card and eight
chapters.

## The files

| File | Use it when |
|---|---|
| `RC_COURIER_00_CONTENTS.mov` | Jack walks the index — "work through all of them, start to finish" |
| `RC_COURIER_01_UTILITY_ORGANISER.mov` | The horseshoe-zip module and the front panel |
| `RC_COURIER_02_SIDE_PANELS_AND_POCKETS.mov` | Side panel, bellows pocket, reinforcement, buckle strap |
| `RC_COURIER_03_BACK_FLAP_CLOSURE_HANDLE.mov` | Back and flap, welted pockets, Cobra closure, handle |
| `RC_COURIER_04_THE_BOTTOM.mov` | Base panel, reinforcement strap, corner reinforcements |
| `RC_COURIER_05_THE_LAPTOP_SLEEVE.mov` | The padded suspended sleeve |
| `RC_COURIER_06_THE_LINING.mov` | The lining, built as a second bag |

| `RC_COURIER_08_ASSEMBLY_AND_BINDING.mov` | Lining drops in, binding closes the top edge |

## Spec

ProRes 4444 · 1920 × 1080 · 30 fps · 173 frames (5.77 s) · straight
(unpremultiplied) alpha · no audio.

## How to use them

Drop one on the track **above** the shot. They carry their own alpha, so no
keying, no blend mode, no masking — just lay it over.

Each card fades up over the first 0.4 s and fades out over the last 0.6 s,
landing on **exactly zero alpha on the final frame**. So you can butt the clip
straight against the footage without a dissolve, and nothing will pop on or off.

If you need one to sit on screen longer, hold the middle: anything between
roughly 0:01.5 and 0:04.7 is the card fully formed and static apart from the
drifting snow, so it freezes or extends cleanly.

## A note on the numbering

The cards are numbered **1 to 8**.

In the tutorial audio Jack refers to the categories by **letter** — "working
through A all the way to H", "this is F in letters", "the final letter is G".
The numbering was chosen deliberately after that was flagged, so the cards and
the voiceover use different labels for the same eight chapters:

| Card | Audio says |
|---|---|
| 1 | A |
| 2 | B |
| 3 | C |
| 4 | D |
| 5 | E |
| 6 | F |
| 7 | G |
| 8 | H |

A lettered set of the same nine cards can be produced from the same project if
that turns out to be the better match in the edit.

## Also worth knowing

The `COLOUR_CODED_A0.pdf` that circulated with this pattern uses a **different**
grouping from the booklet index and the tutorial — it labels the utility
organiser F where the video calls it A. The cards follow the booklet index and
the tutorial, which agree with each other. If a maker ever queries a mismatch,
that sheet is the reason.
