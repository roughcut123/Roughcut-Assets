# Vendored fonts

Committed rather than fetched from Google Fonts at render time, so a render
never depends on the network and always produces identical type.

| Family | Weights | Used for | Licence |
|---|---|---|---|
| Playfair Display | 700, 900 | Headlines and numerals | [OFL 1.1](./Playfair_Display-OFL.txt) |
| EB Garamond | 400, 600, 400 italic | Notes, tag codes | [OFL 1.1](./EB_Garamond-OFL.txt) |
| Pinyon Script | 400 | The small engraved label | [OFL 1.1](./Pinyon_Script-OFL.txt) |

All three are SIL Open Font Licence 1.1 — free to use commercially, including
in monetised video. The licence text ships alongside the font files as the OFL
requires.

They are latin-subset WOFF2 files. If you add copy using characters outside
Latin-1, re-download a fuller subset from Google Fonts.
