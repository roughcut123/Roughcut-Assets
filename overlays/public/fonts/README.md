# Vendored fonts

These are committed rather than fetched from Google Fonts at render time, so a
render never depends on the network and always produces identical type.

| Family | Weights | Used for | Licence |
|---|---|---|---|
| Archivo | 400 / 600 / 700 | Headlines | [OFL 1.1](./Archivo-OFL.txt) |
| IBM Plex Mono | 500 / 600 | Eyebrows, notes, measurements | [OFL 1.1](./IBMPlexMono-OFL.txt) |

Both are SIL Open Font Licence 1.1 — free to use commercially, including in
monetised video. The licence text ships alongside the font files as the OFL
requires.

They are latin-subset WOFF2 files (about 15 KB each). If you add copy using
characters outside Latin-1, re-download the fuller subset from Google Fonts.
